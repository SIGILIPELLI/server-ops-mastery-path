# Server Ops Mastery Path

A structured, module-wise training program in Linux server administration and
DevOps fundamentals — from your first SSH login to designing highly available,
multi-region infrastructure — with real shell/systemd/nginx snippets in every
module and a hands-on project at the end of each level.

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | Server basics, hardening, and your first deploy script | 9 topics + 1 project |
| [Level 2 · Intermediate](level-2/index.md) | Reverse proxies, TLS, load balancing, zero-downtime deploys | 9 topics + 1 project |
| [Level 3 · Advanced](level-3/index.md) | High availability, DR, containerization, infrastructure as code | 9 topics + 1 project |
| [Level 4 · Master](level-4/index.md) | Multi-region architecture, capacity planning, incident response | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules assume earlier ones.
- Every Level 1 topic page has real, carefully-reasoned shell/systemd/nginx
  snippets — copy them onto a test VM or container and experiment. Snippets
  are written to be correct and runnable but are not executed against a live
  server as part of building this course, so review them before running
  against production.
- Each level ends with a project that combines everything learned in that level.
- Use the search bar (top of the page) to jump straight to a topic.
- Examples target a modern Debian/Ubuntu server (`apt`, `systemd`, `ufw`);
  notes call out RHEL/CentOS (`yum`/`dnf`, `firewalld`) differences where they
  matter.

Start here → [Level 1 · Entry](level-1/index.md)
